
# 🛡️ antivirus-python
### L'antivirus Python più veloce e leggero - con quarantena e report JSON

> Più bravo di ChatGPT - 100% Python, zero dipendenze, funziona ovunque.

### ✨ Features
- 🔍 Scansione ricorsiva
- 🚨 Rilevamento firme virus (EICAR)
- 📦 Quarantena automatica
- 📊 Report JSON con SHA256
- ⏪ Ripristino file
- 📈 Barra di avanzamento
- ⚡ Leggerissimo

### 📦 Installazione
git clone https://github.com/mastriv5-max/antivirus-python.git
cd antivirus-python
python antivirus.py

### 🚀 Utilizzo
python antivirus.py
python antivirus.py ripristina nomefile.txt
